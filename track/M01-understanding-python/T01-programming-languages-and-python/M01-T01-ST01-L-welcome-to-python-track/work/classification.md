## Requirement, Logic and Python Syntax

| Instruction                                  | Classification |                Reason                    |
|----------------------------------------------|----------------|------------------------------------------ --------------------                           |                |                                                                                          |                |                                          |
| Check whether the candidate has at least 60% | Logic          | It is a condition that decides something                                                         (is the percentage 60 or more?).         |
| Display the result                           | Requirement    | It states what the program must do (show                                                             an output), not how to do it.            |
| `print("Eligible")`                          | Python Syntax  | It is real Python code using the `print()`                                                                 function, so the computer can run it.    |
| Store the candidate's percentage             | Requirement    | It describes what we need (keep the value                                                             somewhere), without any Python code.     |
| `percentage = 72`                            | Python Syntax  | It creates a variable and assigns it a                                                                 value, following Python's rules.         |
| Reject candidates with active backlogs       | Logic          | It is a rule that makes a decision based                                                             on a condition (active backlogs or not). |
